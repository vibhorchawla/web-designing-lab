About Web Designing

What is Web Designing?

Web designing is the process of creating the layout and appearance of a website. HTML is used to create the structure, while CSS is used for styling.

Bootstrap can also be used to make a website responsive and easier to design.

Basic Web Technologies

HTML

HTML provides the basic structure of a webpage.

CSS

CSS is used to add colours, spacing and other styles.

Bootstrap

Bootstrap provides ready-made classes for responsive websites.
